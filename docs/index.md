# architekton-py

A Copier template for Python projects. It scaffolds a full repo in one answer file.

New here? Read [First 10 Minutes](tutorials/first-10-minutes.md), then
[Why Rules Sit Next to Code](explanations/why-rules-next-to-code.md) for
what the generated `AGENTS.md` field-rules block is doing there.

## How the documentation is structured

Documentation is split into [four categories](https://diataxis.fr), also reachable from the top navigation bar.

- **[Tutorials](tutorials.md)**: Tutorials for installation and typical usage. New users start here.
- **[How-to Guides](how-to.md)**: Practical step-by-step guides for the more experienced user. In the navigation these live under Reference.
- **[Explanations](explanations.md)**: Explanations of how it works and why it works that way.
- **[Reference](reference.md)**: Technical reference material including standards and release notes.

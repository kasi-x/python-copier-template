# architekton-py

A Copier template for Python projects. It scaffolds a full repo in one answer file.

New here? Read <lt-m v="["/>First 10 Minutes<lt-m v="](tutorials/first-10-minutes.md)"/>, then
<lt-m v="["/>Why Rules Sit Next to Code<lt-m v="](explanations/why-rules-next-to-code.md)"/> for
what the generated `AGENTS.md` field-rules block is doing there.

## How the documentation is structured

Documentation is split into <lt-m v="["/>four categories<lt-m v="](https://diataxis.fr)"/>, also reachable from the top navigation bar.

- <lt-m v="**"/><lt-m v="["/>Tutorials<lt-m v="](tutorials.md)"/><lt-m v="**"/>: Tutorials for installation and typical usage. New users start here.
- <lt-m v="**"/><lt-m v="["/>How-to Guides<lt-m v="](how-to.md)"/><lt-m v="**"/>: Practical step-by-step guides for the more experienced user. In the navigation these live under Reference.
- <lt-m v="**"/><lt-m v="["/>Explanations<lt-m v="](explanations.md)"/><lt-m v="**"/>: Explanations of how it works and why it works that way.
- <lt-m v="**"/><lt-m v="["/>Reference<lt-m v="](reference.md)"/><lt-m v="**"/>: Technical reference material including standards and release notes.

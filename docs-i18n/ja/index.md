# architekton-py

Pythonプロジェクト用のテンプレート。単一のファイルで、必要なすべての要素を含むプロジェクト全体を構築します。

こちらに初めていらっしゃるのでしょうか？まず、[最初の10分間](tutorials/first-10-minutes.md)をご覧ください。その後、[「なぜコードとルールが隣接しているのか」](explanations/why-rules-next-to-code.md)について、生成された`AGENTS.md`フィールド・ルールブロックがそこで何をしているのかを理解してください。

- **[の使い方: 経験豊富なユーザー向けの実用的な、手順からのガイド。これらの情報は、ナビゲーションメニューの「参考」セクションにあります。](how-to.md)**
- **[Explanations](explanations.md)**: Explanations of how it works and why it works that way.

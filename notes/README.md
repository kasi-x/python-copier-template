# notes/ — internal

> **INTERNAL.** Everything under `notes/` is the maintainers' working
> material: plans, design drafts, audits, and the task list (`TODO.md`,
> moved here from the repository root). It is not documentation, it is not
> kept current, and it may describe options that were rejected. The
> published documentation is `docs/` (rendered at
> <https://politeuma.github.io/architekton-py>).

- `TODO.md` — the working task list (Japanese); `archive/` holds its
  completed sections.
- `PLAN-*.md`, `plan-*.md`, `Strategy.md` — internal plans.
- `DESIGN-*.md`, `SPEC-*.md` — design drafts; code comments cite a few of
  these by file name where the design reasoning lives.
- `INTERNAL.md` — where the memos moved out of this repository went.
